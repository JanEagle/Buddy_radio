What's new

Every beta comes as a new installer on our Discord. Close Buddy Radio and run the new installer: your settings, stations and keys stay. What's planned next is on the home page.

0.9.0 beta 5

A hint when DCS stays quiet

  • If no mission data arrives within a minute and a half, the Radio log says: "Bridge installed while the DCS server was running? Restart the DCS server once."
0.9.0 beta 4

Green lights

  • Station lights turn green as soon as the SRS server answers, also on SRS servers that don't confirm External AWACS Mode.
  • The live map no longer prints an error into the log when a browser tab is closed.
0.9.0 beta 3

Tankers

  • "Overlord, request tanker" gives the nearest friendly tanker that suits your aircraft, boom or basket, with bearing, range, angels, TACAN and frequency. "Request tankers" lists up to three. See Tankers.
  • Tanker frequencies and TACAN are read from the mission file, including tankers spawned by MOOSE and similar scripts.
  • The app updates the bridge in your DCS profile by itself. Restart DCS once after installing.
0.9.0 beta 2

A tower for every airfield

  • One Tower on 251.500 serves every airfield on every map. Name the airfield, or just say Tower for the one you're nearest.
  • ATIS on request: "Tower, request information."
  • Beta 1's Rosh Pina tower and ATIS switch over by themselves. Towers set up for one airfield keep working.
  • The precision approach uses your radio callsign.
  • The status column on the Radio page no longer runs off the window.
0.9.0 beta 1

The Windows app

  • A Windows installer with a setup page for each part: DCS, SRS, Claude, Discord, stations and the map.
  • Keys are kept in Windows Credential Manager.
  • The DCS bridge and the scripting change are set up from the app.

Buddy Radio is a community project for DCS World groups, free to use with your own Claude key.
