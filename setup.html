Setup

Buddy Radio is a Windows app. Install it on the PC that hosts your missions, next to the DCS server and the SRS server. Pilots install nothing: they just tune their radios.

Get the installer

Buddy Radio is in a closed beta. Join our Discord and ask for early access, and we'll send you the installer.

Ask for early access

What you need

Check these before you install. Speech recognition runs on the processor whenever someone talks, so a stronger CPU means quicker replies.

A Windows PC
Windows 10 or 11, 64-bit, the one that runs your DCS server or hosts your multiplayer missions. 16 GB of memory at least, 32 GB is comfortable with a big mission like Foothold.
DCS World
The DCS World dedicated server, or DCS itself if you host from your own game.
The SRS server
DCS-SRS with its server running on the same PC or your network. Pilots connect to it with the normal SRS client.
A Claude API key
Your own key from console.anthropic.com with a few dollars of prepaid credit. A busy evening with five pilots costs well under a dollar. Step 1 shows how to get one.
Disk and internet
About 2 GB free. The first start downloads the speech model and the voices, so it needs internet and takes a few minutes.
Optional
A Discord server for target and greenie-board posts, and a tablet or phone for the live map.

Before you install

  1. Get a Claude API key

    Go to console.anthropic.com and make an account. Under Billing, buy a few dollars of credit and leave auto-reload off, so the credit you bought is the most you can ever spend. Then open API Keys, choose Create Key and copy it.

    The key is shown only once. Keep it in a password manager until the app asks for it, and never post it in Discord or a chat: anyone with the key spends your credit.

  2. Turn on External AWACS Mode in SRS

    In the SRS server's settings, switch External AWACS Mode on and set a password for each side. The Buddy stations join SRS this way, like an AWACS player. You'll type the blue password into the app in step 5.

Install the app

  1. Run the installer

    Double-click BuddyRadio-Setup.exe. Because the beta isn't signed with a certificate yet, Windows warns you first. Choose More info, then Run anyway.

    When Windows asks whether the app can make changes to your device, choose Yes. Then click through the installer: keep the suggested folder, tick the desktop shortcut if you want one, choose Install, and leave Start Buddy Radio ticked at the end.

First-time setup in the app

The first time it opens, the app walks you through its setup pages in order. A yellow ! in the left column marks a page that still needs something. Press Save and continue at the bottom of each page to go to the next.

  1. DCS: install the bridge

    The bridge is a small script that sends the mission's positions, airfields and weather to the app. Check both folders:

    • DCS profile is the Saved Games folder of the DCS that runs your missions. For a dedicated server that's usually DCS.dcs_serverrelease. If you host from your own game, it's DCS.
    • DCS install folder is where that DCS is installed, for example C:\Program Files\Eagle Dynamics\DCS World Server.

    Press Install the bridge. Then press Allow scripting and choose Yes when Windows asks. Both lights turn green. Restart the DCS server once so it loads the bridge.

    DCS updates undo the scripting change. If Buddy stops getting mission data after an update, come back to this page and press Allow scripting again.

  2. SRS: connect to your SRS server

    Leave the address as 127.0.0.1:5002 if SRS runs on this PC. Type the External AWACS Mode password from step 2, pick the side the stations work for, and press Test the connection.

  3. Claude: paste your API key

    Paste the key from step 1 and keep Haiku selected: it's the fastest and cheapest. Press Test the key. "The key works" in green means you're done.

    The key is stored in Windows Credential Manager, never in a file. If Anthropic says the account has no credit, add some under Billing in the console.

  4. Discord: post targets and grades (optional)

    In Discord, open Server Settings, Integrations, Webhooks. Make a New Webhook for your targets channel, choose Copy Webhook URL and paste it in the app. Do the same for your greenie-board channel. Press Send a test next to each one.

    Leave a box empty to skip that channel. Anyone with a webhook address can post in that channel, so keep them private.

  5. Stations: check the frequencies

    The five stations come ready to use. Double-click one to change its frequency or voice. To add a tower for another airfield, press Add a tower and ATIS and write the airfield name exactly as DCS shows it, for example Kutaisi or Nellis.

    Speech recognition: small.en suits most PCs. Pick base.en if replies feel slow.

  6. Map: tablets on your network (optional)

    Leave Serve the live map ticked. To open the map on a tablet or phone at home, press Allow tablets through the firewall and choose Yes when Windows asks.

Go on the air

  1. Start everything in this order

    First the DCS server with a mission running, then the SRS server, then Start the stations on the app's Radio page. Every light turns green within a minute. The very first start takes longer while it downloads the speech model and voices.

    Now get in a jet, tune 251.000 and call "Overlord, [your callsign], radio check". The radio guide lists everything you can ask each station.

Updates and removal

Each new beta comes as a new installer on our Discord.

  • To update, close Buddy Radio and run the new installer. Your settings, stations and keys stay.
  • Settings and the downloaded voices are in %LOCALAPPDATA%\BuddyRadio. Your keys are in Windows Credential Manager under BuddyRadio.
  • To remove it, use Windows Settings, Apps, Buddy Radio, Uninstall. The bridge stays in your DCS profile, in Scripts\Buddy and Scripts\Hooks; delete those two files if you want DCS back exactly as it was.

Put the live map online

On your home network the map opens from the Radio page with Open the live map. To open it from this website, wherever your pilots are, the app needs a secure public address. A tunnel gives it one without opening ports on your router.

  1. Make a map key

    On the app's Map page, press Make one next to Map key, so only people with the key see your mission. Restart the stations.

  2. Start a tunnel

    Either Cloudflare (free, new address every time):

    cloudflared tunnel --url http://localhost:8080

    or Tailscale Funnel (free, the same address every time):

    tailscale funnel 8080

  3. Connect the map

    Open the live map, choose Connect, and paste the https address the tunnel printed and your key. Share the link it gives you with your group.

When something's wrong

You seeWhat to do
DCS mission data stays at waiting for a missionThe bridge isn't sending. Check that the DCS profile on the DCS page belongs to the DCS that runs the mission (server or game), and restart DCS once after installing the bridge. The DCS log in that profile's Logs folder should say "BuddyBridge started".
SRS server: not reachable, is SRS running?Start the SRS server first, then check the address on the SRS page.
A station says wrong SRS password or sideThe password on the SRS page must match the External AWACS Mode password of the side you picked.
A station says turn on External AWACS Mode in SRSDo step 2 in the SRS server settings, then start the stations again.
Port 10081 is busy in the logAnother copy of Buddy is already running, for example an older version started by hand. Close it.
A station says "say again"It couldn't make sense of the call. Read the rx line in the log to see what it heard, and keep calls short.
The DCS page says scripting is blocked againA DCS update put the original file back. Press Allow scripting again.

Still stuck? Ask in the help channel on our Discord and paste the last lines of the log from the Radio page. Never paste your API key or webhook addresses.
