Questions

Is it free?

Yes. The app is free to download and use. It talks to Claude with your own API key, so you pay Anthropic directly for what your group uses, and nobody else sees your bill. If you'd like to help it grow, see Support the project.

Do pilots need to install anything?

No. Only the PC that hosts the mission runs Buddy Radio. Pilots use the normal SRS client and tune the frequency.

What do I need to run it?

A Windows 10 or 11 PC that runs DCS or the DCS server, an SRS server, and a Claude API key with a few dollars of credit. The setup page has the full list and every step.

Does it work when I host from my own game?

Yes. Run Buddy Radio on the same PC as DCS and the SRS server, and choose your normal DCS profile on the app's DCS page instead of the server one.

Which maps and aircraft does it work with?

Every map. Tower serves the airfields of whichever map is running, Overlord picks a boom or basket tanker to suit your aircraft, and Paddles works with the carriers in DCS. Radio calls are in English.

Can several pilots talk at once?

Yes. Every station works on its own, so a call to Overlord and a call to Tower are answered at the same time. Calls to the same station are answered one after another, like a real controller.

Can it run next to SkyEye, LotATC or other SRS tools?

Buddy joins SRS like an AWACS player, so other tools can share the server on other frequencies. Don't put two controllers on the same frequency. We haven't tested every combination, so tell us on Discord how yours goes.

Costs

Your Claude bill

What does it cost to run?

Most calls are worked out on your PC and cost nothing: bogey dope, picture, tanker calls, taxi, ATIS, threat warnings, talk-downs, coordinates and the whole Paddles trainer. Only questions in your own words go to Claude, using Haiku, the fastest and cheapest model. An evening's flying usually comes to cents.

How do I keep it in check?

Buy prepaid credit in the Claude Console and leave auto-reload off, so the credit you bought is the most you can spend. The console shows your usage day by day.

Privacy

What leaves your PC

  • Voices stay on your PC. Speech recognition and the station voices run locally. No audio is sent anywhere.
  • Claude gets what a question needs. For calls that go to Claude, the written text of the call, the pilot's SRS name and callsign, and the mission data for that call (positions, airfield, weather) go to Anthropic's API under your key. Buddy also sends short passages from the manuals in its folder when it looks something up.
  • Discord only if you set it up. With webhooks added, target coordinates and carrier grades are posted to your channels.
  • The live map stays on your network unless you put it online with a tunnel. A map key keeps it to the people you share it with.
  • First start downloads the speech model and the voices from Hugging Face.
  • Nothing comes to us. No accounts, no analytics, no usage data.

Where are my keys kept?

In Windows Credential Manager, under BuddyRadio. They're never written to a file, and the app never shows them again.

Safety

Admin rights and warnings

Why does it ask for admin rights?

Three times, each for one job: the installer puts the app in Program Files, Allow scripting changes one file in your DCS install folder, and Allow tablets through the firewall lets phones and tablets on your network open the live map.

What does Allow scripting change?

DCS stops mission scripts from using files and the network unless its MissionScripting.lua allows it. The bridge needs the network to pass mission data to the app on your PC, so Buddy turns those limits off and keeps the original as MissionScripting.lua.buddy-backup. Many server tools ask for the same change.

It applies to every mission on that DCS, so only run missions you trust. DCS updates put the original file back, and the app's DCS page shows when to allow scripting again.

Why does Windows say it protected my PC?

The beta isn't signed with a code-signing certificate yet, so Windows doesn't know the publisher. Choose More info, then Run anyway, and only for the installer you got from our Discord. A certificate is the first thing support for the project pays for.

My antivirus flagged it. Is it safe?

Unsigned apps built into machine code are sometimes flagged by mistake. Only run the installer from our Discord, and tell us which antivirus flagged it so we can report the false alarm.

Can I see what runs inside DCS?

Yes. The bridge is a plain Lua script you can read: Scripts\Buddy\buddy_bridge.lua in your DCS Saved Games folder, loaded by Scripts\Hooks\buddy_bridge_hook.lua.

Help

Bugs and questions

Ask in the help channel on our Discord. For a bug, say what you called and what happened, and paste the last lines of the log from the app's Radio page. Never paste your API key or webhook addresses.
